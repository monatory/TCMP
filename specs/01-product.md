# 01 · 제품 스펙

## 비전

**"동굴과 터널 사이에서, 지금 내가 어디 서 있는지를 비추는 거울."**

TCMP는 사용자의 현재 마음 상태를 4개 축으로 진단해 16개 코드 중 하나로 매핑하고, 그에 맞는 강점·그림자·**오늘 할 행동 하나**를 제시하는 자가진단 도구다.

---

## 차별점 (왜 MBTI가 아닌가)

1. **변화를 전제로 함** — "당신은 이런 사람"이 아니라 "지금 여기 서 있다". 결과 화면에 "한 달 뒤 다시 진단" 권유 명시.
2. **처방(Prescription) 중심** — 단순 성격 묘사가 아닌, 오늘 24시간 안에 할 구체 행동 하나가 핵심 가치.
3. **빛/어둠 스펙트럼** — 16코드를 5개 영역(빛 → 빛에 가까운 → 균형 → 어둠에 가까운 → 어둠)에 배치해 변화 방향을 시각화.

---

## 타깃 사용자

| 사용자 | 사용 맥락 |
|---|---|
| 중·고·대학생 | 진학·진로 상담에서 자기이해 도구 |
| 일반 독자 | 책을 읽고 자기 자리를 확인 |
| 상담사·코치 | 상담 워밍업, 변화 추적 |

---

## MVP 범위 (Phase 1)

**포함**
- 20문항 5점 척도 진단
- 자동 채점 (역채점 포함) → 4글자 코드 도출
- 결과 화면 (코드, 영역, 점수, 강점·그림자·처방)
- 5영역 스펙트럼 시각화
- localStorage 기반 진단 이력 저장 (최대 30개)
- 재진단 기능
- 결과 공유 (navigator.share / 클립보드)
- 모바일 우선 반응형

**제외 (Phase 2 이후)**
- 회원가입·로그인
- 백엔드·DB
- SNS 카드 자동 이미지 생성 (html2canvas)
- 결과 비교 대시보드 (카운셀러 모드)
- Claude API 호출
- 다국어
- 푸시 알림 (재진단 리마인더)

---

## 성공 기준

1. **정확성**: 채점 결과가 원본 워크북의 채점 방식과 100% 일치
2. **완성도**: 16개 코드 모두 결과 화면에서 정상 표시 (빈 필드·undefined 없음)
3. **속도**: 첫 로드 후 화면 전환 200ms 이내
4. **모바일**: 360×640 viewport에서 가로 스크롤·텍스트 잘림 없음
5. **충실도**: 책의 톤(차분·문예적)이 디자인에 그대로 반영

---

## 비기능 요구사항

- 정적 사이트로 배포 가능 (`next build && next export` 가능)
- 외부 API 호출 없음 (오프라인 사용 가능)
- 접근성: 키보드 네비게이션 가능, 색상 대비 WCAG AA 통과
- 다크모드: 이번 단계에서는 미지원 (책의 크림 종이 느낌이 정체성)

| 화면 ID | 이름 | 역할 |

| 5 | 질문 5 — 지표 4 관계와 확장 | Q17~Q20 |
